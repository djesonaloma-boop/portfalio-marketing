# JASON DIGITAL — Portfolio Marketing

Portfolio numérique de Jason Aloma, créateur congolais 🇨🇩.

## Fonctionnalités

- Page d'accueil responsive
- Présentation des services
- Présentation du créateur
- Pages d'études de cas
- Formulaire préparant un message WhatsApp
- Pages de témoignages
- Fichiers SEO
- Configuration Vercel

## Structure

- `index.html` : accueil
- `services.html` : services
- `a-propos.html` : présentation
- `temoignages.html` : avis clients
- `contact.html` : contact
- `404.html` : page d'erreur
- `cas/` : études de cas
- `css/` : styles
- `js/` : scripts
- `data/cases.json` : données des projets
- `img/` : logos et photos
